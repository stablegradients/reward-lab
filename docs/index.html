Policy updates

The task: one prompt with 21 possible answers, each carrying a fixed reward between 0 and 1. Every update samples 32 answers from the current policy, scores them, weights the group with the algorithm’s rule, and shifts probability toward the better ones. All algorithms start from the same distribution and share the random draws; they differ in how they turn each group’s scores into weights.
